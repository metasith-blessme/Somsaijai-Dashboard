# 0001: Hybrid Shared COGS Allocation

We decided to partition global Shared COGS into two distinct categories: **Fruit COGS** and **Revenue-Proportional COGS** (Ice and Packaging). **Fruit COGS** is allocated based on actual branch usage derived from daily sales report records, while **Revenue-Proportional COGS** is allocated proportionally based on branch revenue shares. This hybrid model prevents unfair cost distribution caused by varying product sales profiles across branches while keeping common, untracked overhead simple to allocate.
